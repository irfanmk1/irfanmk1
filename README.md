## 🚀 Featured Project

### 📊 [DataStack Insights](https://github.com/irfanmk1/datastack-insights)

**DataStack Insights** is my CS50 Final Project — an interactive web application for analyzing job-market data and identifying the technical skills employers are looking for in data-related roles.

#### What I built

* Integrated the **Adzuna Job Search API** to collect job-posting data
* Built an **ETL pipeline** to process and structure raw data
* Designed a **SQLite database** for storing job and skill information
* Developed pattern-based **technical skill extraction**
* Analyzed the demand for different technical skills
* Built interactive visualizations using **Chart.js**
* Developed the application backend with **Python & Flask**
* Created a responsive interface using **HTML, JavaScript, and Tailwind CSS**

**Tech:** `Python` `Flask` `SQLite` `JavaScript` `Chart.js` `Tailwind CSS` `REST API`

🌐 **Live Demo:** [datastack-insights.onrender.com](https://datastack-insights.onrender.com/)
